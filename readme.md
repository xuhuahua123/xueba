# 学习平台搭建

**一、 产品定位**
	一个面向个人/小团队的轻量化在线学习系统，支持本地 Markdown 讲义渲染、AI 辅助理解、题库练习以及错题管理，旨在提高结构化知识的学习与复盘效率。

**二、 技术选型验证**

- **前端**：Vue 3 + Vite + ui（什么ui css好一点） + Markdown 渲染库（如 `markdown-it` 或 `marked`）
- **后端**：Node.js + Fastify
- **数据库**：SQLite（使用 `better-sqlite3` 或 `Prisma` ORM）
- **AI 接口**：deepseek api接口

**三、 核心功能需求**

1. 讲义学习模块

- **目录树渲染**：后端读取本地 Markdown 文件夹目录，自动生成左侧的层级菜单。

- **讲义展示**：前端解析 Markdown 语法，支持代码高亮、表格、图片等基础渲染。

- **学习进度标记**：用户可将某篇讲义标记为“未开始”、“学习中”或“已完成”，数据写入 SQLite。

  AI 辅导模块

- **白话文切换/双语对照**：针对当前讲义，提供“AI 大白话版本”。（建议在后端触发生成，生成后将文本存入 SQLite，避免重复请求 API）。

  练习题模块

- **题目展示**：支持单选题、多选题、判断题三种基础题型。

- **随堂练习**：在每篇讲义末尾，拉取与该讲义 ID 绑定的练习题进行测试。

- **实时批改**：提交后立即显示正确与否，并展示解析。

  错题本模块

- **自动收录**：用户在“练习题模块”中答错的题目，系统自动将其 ID 与错误次数写入错题本记录表。
- **错题重练**：提供单独的“错题本”入口，支持按讲义分类或全局随机抽取错题进行重做。
- **自动移除**：当某道错题在重练中连续回答正确超过 N 次（可配置，如 2 次），自动从错题本中移除，或标记为“已掌握”。
